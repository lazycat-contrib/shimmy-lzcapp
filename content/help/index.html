Shimmy

OpenAI-compatible API

在自己的设备上运行 AI。Run AI on your own device.

Shimmy 通过兼容 OpenAI 的接口运行本地 GGUF 模型。API 与此页面使用相同域名。Shimmy runs local GGUF models through an OpenAI-compatible API. The API uses the same domain as this page.

开始使用Get started

准备模型Add a model

将受支持的 .gguf 模型放入 Shimmy 的模型目录。Place a supported .gguf model in Shimmy's model directory.

查询模型名称Find the model ID

请求 /v1/models，复制返回结果中的模型 ID。Request /v1/models and copy a model ID from the response.

发送请求Send a request

将模型 ID 填入 model，调用对话接口即可开始生成。Use that ID as model, then call the chat endpoint to generate a response.
